# 急救药品识别

医院场景下，机器狗携带急救药箱到达患者身边。摄像头看整篮药盒，demo阶段产品按颜色识别药品，电脑用中文语音报名称。本系统只做送达与识别，不替代医护判断，也不替代 120 / 院内急救。

摄像头：**Insta360 Link 2C**（俯拍药篮）。语音：Mac `say`。

## 识别规则

- 整幅画面当作药篮，不用画框。
- 清单里的颜色稳定出现后，**从画面里消失约 1 秒**才算拿出。在画面里换位置不报。
- 报「拿出××」。阿司匹林、沙丁胺醇等特殊药品会加一句「请医护确认」。
- 某一种药累计拿出次数超出使用上限后，右上角出现「补货」；点按清零。

## 药品两层级


| 类别    | 颜色  | 药品        | 拿出时语音           |
| ----- | --- | --------- | --------------- |
| 现场急救  | 绿   | 肾上腺素自动注射器 | 拿出肾上腺素自动注射器     |
| 现场急救  | 黄   | 口服葡萄糖片    | 拿出口服葡萄糖片        |
| 现场急救  | 蓝   | 纳洛酮鼻喷雾    | 拿出纳洛酮鼻喷雾        |
| 须核对后用 | 红   | 阿司匹林咀嚼片   | 拿出阿司匹林咀嚼片，请医护确认 |
| 须核对后用 | 白   | 沙丁胺醇吸入剂   | 拿出沙丁胺醇吸入剂，请医护确认 |


**现场急救**：场景相对明确，可按医嘱、说明书或急救流程尽快协助，同时启动急救响应。  
**须核对后用**：须先排除禁忌或确认处方与诊断，拿错风险更高。

胺碘酮注射液 + AED 属于院内高级生命支持，仅有资质医护在监护、除颤和静脉/骨内通路条件下使用，**未进入识别清单**。

## 使用方式

1.关掉 Zoom、影石 Link 软件等占用摄像头的程序。

2.系统设置 → 隐私与安全性 → 摄像头，打开「终端」。

3.Link 2C 拨开挡片，关掉 Auto Framing。

```bash
cd "/Users/wyd/压力传感器"
./run_link2.sh
```

4.脚本建虚拟环境、装依赖，并用 Link 2C 打开识别窗口。窗口名 `basket-sentry`。指定设备：

```bash
./run_link2.sh --source link2    # 默认，Insta360 Link 2 / 2C
./run_link2.sh --source x4       # 影石 X4 USB 摄像头
./run_link2.sh --source 0        # AVFoundation 序号
```

本机查看摄像头列表：

```bash
ffmpeg -f avfoundation -list_devices true -i ""
```
